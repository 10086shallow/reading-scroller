# 阅读模拟器

一个按人的阅读节奏自动滚屏的小工具。不匀速、不机械，滚几行、停一下、偶尔往回翻一点，像真的在读。

![界面截图](docs/screenshot.png)

适合长文章、小说、文档、PDF —— 解放双手，也解放滚轮。

---

## 特点

- **滚动节奏像人**：每次滚 1~3 格，间隔在基准值的 0.65~1.6 倍之间浮动，没有固定节拍
- **会停下来"看完这一段"**：约 5% 的概率额外多停 1.2~3.5 秒
- **会回头看一眼**：往下读 18~46 格后，往上翻回这段的 25% 左右，再继续往下
- **开箱即用**：内置精简的 Python 运行时，**不需要安装任何环境**，解压双击就能跑
- **零联网**：不访问网络、不读环境变量、不写注册表，只读写自己目录下的两个文件

## 快速开始

1. 下载 [阅读模拟器-v1.0-win64.zip](../../releases) 解压，或直接 clone 本仓库
2. 双击 `启动阅读模拟器.bat`
3. 屏幕右下角出现小窗口，3 秒后自动开始
4. 把鼠标移到你要阅读的窗口上 —— 它就开始滚了

> 窗口可以按住任意拖动。**鼠标要停在目标窗口上**，因为 Windows 的滚轮消息是发给指针下方的窗口的。

## 界面与快捷键

| 控件 | 作用 |
|---|---|
| 慢读 / 正常 / 快读 | 三档速度（基准间隔 1.7s / 1.1s / 0.7s），选择会被记住 |
| 开始 / 暂停 | 控制滚动 |
| 退出 | 关闭程序 |

| 键 | 作用 |
|---|---|
| `F8` | 隐藏 / 显示窗口 |
| `F9` | 暂停 / 继续 |
| `F10` | 停止 |
| `F11` / `F12` | 切到更慢 / 更快一档 |

## 想改参数？

打开 `app.py`，文件顶部有一组常量：

```python
STEP_MIN, STEP_MAX = 1, 3      # 每次滚动的格数范围
REVIEW_RATIO = 0.25            # 回看幅度，0.25 表示回 25%
REVIEW_EVERY = (18, 46)        # 下滑多少格回看一次
SPEEDS = (1.7, 1.1, 0.7)       # 三档速度的基准间隔（秒）
```

改完保存，重新启动即可。

## 工作原理

界面是用 `ctypes` 直接调 Win32 API 自绘的（圆角、深色、无边框），不依赖 tkinter 或任何 GUI 库。滚轮通过 `mouse_event(MOUSEEVENTF_WHEEL)` 发送，和真实滚轮事件走同一条路径，浏览器、PDF 阅读器、Word 都认。

程序只有 5 个 import：`ctypes`、`ctypes.wintypes`、`os`、`random`、`sys`。

## 打包成单文件 exe

需要先装 PyInstaller：

```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --icon icon.ico app.py
```

产物在 `dist/` 下，单个文件约 8MB，不再需要 `runtime/` 目录。

## 常见问题

**双击没反应？** 看同目录有没有生成 `error.log`，那是异常记录。另外确认 `runtime/` 完整。

**杀毒软件报警？** 程序只做本地滚轮模拟，不联网、不碰注册表。部分杀软对"模拟输入"类程序敏感，加信任即可。

**为什么不用 PyQt / tkinter？** 这台开发机上的 Python 没有 tkinter，`csc.exe` 也被策略拦着，所以走纯 Win32 自绘——反而是最轻的方案，运行时也省下了几个 MB。
