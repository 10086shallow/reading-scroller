========================================
  阅读模拟器  v1.0
========================================

【这是什么】

一个自动滚屏的小工具。它会按人的阅读节奏帮你滚轮下滑——
不是匀速机械地滚，而是滚几行、停一下、偶尔往上翻一点回看，
再继续往下，如此循环。

适合长文章、小说、文档、PDF 阅读时解放双手。


【怎么用】

1. 把整个文件夹解压到任意位置，比如 D:\工具\阅读模拟器
   （不要放在 C:\Program Files 这类需要管理员权限的目录）
2. 双击「启动阅读模拟器.bat」
3. 屏幕右下角会出现一个小窗口，3 秒后自动开始
4. 把鼠标移到你要阅读的窗口上，它就开始滚了

窗口可以按住拖动到屏幕任意位置。


【界面说明】

  阅读速度    慢读 / 正常 / 快读，点一下切换，会自动记住
  开始/暂停   控制滚动
  退出        关闭程序


【快捷键】

  F9    暂停 / 继续
  F10   停止
  F8    隐藏 / 显示窗口
  F11   切到更慢一档
  F12   切到更快一档


【它是怎么滚的】

真实的阅读不是匀速的，所以程序里加了这几层随机：

  · 每次滚 1~3 格，间隔在基准值的 0.65~1.6 倍之间随机浮动
  · 约 5% 的概率遇到"长段落"，额外多停 1.2~3.5 秒
  · 往下读了 18~46 格后，会往上翻回这段的 25% 左右，
    像人回头看一眼刚才读过的内容，然后再继续往下

三档速度的基准间隔分别是 1.7 秒 / 1.1 秒 / 0.7 秒。


【常见问题】

Q: 双击后没反应，窗口没出现？
A: 先看同目录下有没有生成 error.log，有的话把内容发给作者。
   另外确认 runtime 文件夹完整，不要单独删改里面的文件。

Q: 杀毒软件报警？
A: 程序只做本地滚轮模拟，不联网、不读写其他文件、不写注册表。
   部分杀软对"模拟输入"类程序比较敏感，可以加入信任列表。

Q: 鼠标放在哪才会滚？
A: Windows 的滚轮消息是发给鼠标指针下方的窗口的。
   所以请把鼠标停在要滚动的窗口上，不要停在模拟器窗口上。

Q: 想改滚动幅度、回看比例？
A: 用记事本打开 app.py，文件顶部有一组参数：

     STEP_MIN / STEP_MAX   每次滚动格数范围
     REVIEW_RATIO          回看幅度（0.25 表示 25%）
     REVIEW_EVERY          每下滑多少格回看一次（格数范围）
     SPEEDS                三档速度的秒数

   改完保存，重新启动即可。

Q: 为什么不打包成一个 exe？
A: 程序用 Python 编写。runtime 文件夹里已经放了精简过的 Python
   运行时，你不需要另外安装 Python，解压即用。
